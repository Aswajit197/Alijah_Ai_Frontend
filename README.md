# Elijah AI — Company Frontend

Next.js 14 web application for contractor companies (owners, dispatchers, office managers, field technicians) using the Elijah AI platform.

For full setup, running, and testing instructions, please refer to:
👉 **[HOW_TO_RUN.md](HOW_TO_RUN.md)**

## Summary of Capabilities
- **Unified AI Inbox:** Listen to real audio recordings, inspect automated call transcripts, read AI triage summaries, and send two-way SMS messages to customers.
- **Leads & Pipeline:** Real-time visibility into incoming calls, lead qualification, and automatic conversion into work orders.
- **Schedule & Dispatch Board:** Technician swimlanes, drag-and-drop dispatch, time windows, and early dispatch safeguards.
- **Public Booking Widget:** Contractor-branded public booking page at `/book/[tenantSlug]` with integrated browser WebRTC voice calling directly to the AI receptionist.
- **Customer CRM:** Comprehensive customer database with full address, job history, and service notes.
